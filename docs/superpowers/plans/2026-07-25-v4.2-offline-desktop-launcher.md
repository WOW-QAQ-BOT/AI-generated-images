# v4.2 Strict-Offline Desktop Launcher Implementation Plan

> **归档状态说明（2026-07-26）：** 本计划中的未勾选框保留原始执行清单，
> 不表示实现尚未完成。最终自动化与发布证据记录在设计文档和 v4.2 发布报告中；
> 受当前 Tcl/Tk 环境限制的隐藏/交互式窗口冒烟测试仍未宣称完成。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Windows Tkinter launcher that performs an offline preflight, starts and stops the Gradio workbench without automatic downloads, and leaves dependency installation in a separate explicit script.

**Architecture:** Keep all launcher behavior in small, UI-independent modules under `launcher/`; `tk_app.py` is an adapter over checks, process control, redaction, and view-model interfaces. Remove the implicit remote Stable Diffusion fallback so launcher and web UI can start safely with zero local models while API generation remains an explicit online action.

**Tech Stack:** Python 3 standard library (`tkinter`, `subprocess`, `socket`, `threading`, `queue`, `webbrowser`), Gradio, existing inference modules, Windows batch scripts, pytest-style tests.

## Global Constraints

- Startup, preflight, local model discovery, and local generation must not initiate external network access.
- Set `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `HF_DATASETS_OFFLINE=1`, and `HF_HUB_DISABLE_TELEMETRY=1` in the Gradio child environment.
- Add `127.0.0.1,localhost` to both `NO_PROXY` and `no_proxy`; preserve all external proxy variables.
- `启动工作台.bat` and the Tkinter launcher must never run pip or install/download anything.
- `安装依赖.bat` is the only dependency installation entry and installs `requirements.txt`, never `requirements-dev.txt`.
- Prefer the user's existing interpreter; launch `app.py` with the launcher's `sys.executable`.
- Tkinter is the only UI dependency in v4.2; do not add PySide6.
- No local model is a warning, not a launcher-blocking error; local generation must be disabled while API generation remains available.
- Launcher logs live in memory only and must be redacted before display or clipboard copy.
- Do not add automatic model downloads, executable packaging, persisted secrets, or unrelated image-quality features.
- This project copy has no independent `.git`; do not initialize one. Suggested commit messages below are for a future repository import, while this run uses test checkpoints.

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class LocalModelUiState:
    choices: tuple[str, ...]
    value: str | None
    can_generate: bool
    message: str


def local_model_ui_state(models):
    choices = tuple(str(model) for model in models if str(model).strip())
    value = "anything-v5" if "anything-v5" in choices else (choices[0] if choices else None)
    if not choices:
        return LocalModelUiState(
            choices=(),
            value=None,
            can_generate=False,
            message="没有检测到完整本地模型。本地生成已禁用；API 作画仍可使用。",
        )
    return LocalModelUiState(
        choices=choices,
        value=value,
        can_generate=True,
        message=f"找到 {len(choices)} 个完整本地模型。",
    )
```
